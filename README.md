# clinical-data-sql-project
Beginner-friendly Clinical Data Management SQL project using MySQL Workbench with relational database design and clinical trial data.

## Overview

This project demonstrates SQL database design for a Clinical Data Management scenario using MySQL.

## Database

The project contains two related tables:

- Participants
- Adverse Events (AE)

The tables are connected using `SUBJ_ID`, which represents the unique subject identifier in a clinical trial.
